이용약관

시행일: 2026년 11월 5일

1. 서비스

podocut은 사용자의 컴퓨터에서 실행되며, 사용자가 연결한 YouTube·Instagram·TikTok·Threads·Facebook 계정에 사용자가 고른 영상을 게시하거나 예약하는 도구입니다.

2. 사용자의 책임

  • 게시하는 영상과 글에 대한 권리(저작권·초상권 등)를 가지고 있어야 합니다.
  • 각 플랫폼의 약관과 커뮤니티 가이드를 지켜야 합니다. 예: YouTube 서비스 약관, Instagram 이용약관, TikTok 서비스 약관.
  • 본인이 관리할 권한이 있는 계정만 연결해야 합니다.

3. 플랫폼과의 관계

podocut은 Google, YouTube, Meta, Instagram, Facebook, Threads, TikTok과 제휴하거나 그들이 보증하는 서비스가 아닙니다. 각 플랫폼은 API 정책에 따라 게시를 제한하거나 거절할 수 있으며(예: 심사 전 앱의 공개 범위 제한, 게시 횟수 제한), podocut은 이를 대신 보장할 수 없습니다.

4. 보증의 부인과 책임의 제한

podocut은 "있는 그대로" 제공됩니다. 네트워크 오류나 플랫폼 정책 변경으로 게시가 실패하거나 늦어질 수 있습니다. 실패한 게시는 자동으로 다시 올리지 않으므로, 사용자가 결과를 확인한 뒤 다시 시도해야 합니다. 관련 법령이 허용하는 범위에서 podocut 개발자는 사용으로 생긴 간접적 손해에 책임지지 않습니다.
